# 📖 Project Overview

This project was developed using:

- HTML5
- CSS3
- JavaScript
- React
- Fetch API
- Responsive Design Principles
- Git & GitHub Collaboration Workflow

The application displays information about planets retrieved from an external API and allows users to interact with the interface through smooth scrolling navigation and a contact form.

---

# ✨ Features

## ✅ Implemented Functionalities

- Smooth scroll to planet section
- Smooth scroll to contact form
- Dynamic planet data fetching using Fetch API
- Responsive design for desktop and mobile
- Reusable React components
- Video background with autoplay, muted, and loop
- Contact form validation
- Form submission feedback message
- Public deployment
- Git collaboration using Pull Requests
